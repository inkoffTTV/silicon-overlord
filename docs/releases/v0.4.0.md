## Silicon Overlord 0.4.0 — аккаунты и голос персонажа

**Эту версию нужно один раз скачать целиком** (архив ниже, ~170 МБ): рядом с игрой появилась папка `voice/` с синтезатором речи, а автообновление меняет только сам файл игры. Дальше снова всё обновляется само.

### Аккаунты: играйте с любого ПК
- Меню → плашка «Аккаунт» → «Регистрация». Все ваши компании сразу привязываются к аккаунту.
- На другом ПК: «Войти» с тем же логином и паролем, там будут те же компании.
- Без пароля: «Код переноса» из 8 символов, действует 10 минут, одноразовый.
- Пароль не передаётся по сети, сервер хранит только зашифрованный отпечаток. Подбор пароля блокируется.

### Голос персонажа в духе R.E.P.O
- Сообщения чата персонаж читает вслух своим голосом: синтезатор Piper прямо в игре, без интернета.
- У каждого игрока своя высота голоса, плюс металлический призвук и помехи как у рации. Чем дальше говорящий, тем тише.
- Настройки → Звук: «Персонаж / Голоса Windows / Робот / Выкл», ползунок высоты, кнопка «Проверить голос».
- Английский голос встроен. Русский текст пока читается голосом Windows: у подходящей русской модели нужно уточнить лицензию.

### Ещё
- В меню вместо адреса сервера написано «Сервер: Стокгольм».
- Понятное сообщение, если сервер недоступен.
